To demonstrate synchronization between reader and writer threads accessing a shared resource using semaphores. Multiple readers may read concurrently, while a writer requires exclusive access.

3. Interpretation

  • Three readers access the shared resource concurrently.
  • The active-reader count decreases as each reader finishes reading.
  • Both writers wait for exclusive access while readers are active.
  • After all readers finish, the writers update the shared value one at a time.
  • The shared value changes from 0 to 1 and then to 2.
